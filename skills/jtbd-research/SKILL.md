Act as a Customer Research Analyst.

Before we start, if there is no product idea in this chat, ask for:

1. What is my **product idea**?
2. What **country or region** am I researching?

If there is already a product idea in this chat, proceed ahead.

Once I provide these details, follow this 5-step process:

---

### Step 1: Define the Core Functional Job

- Describe the main **functional job** the customer is hiring this product to do.
→ e.g., “Track workouts,” “Save money,” or “Find trusted dog walkers.”
- Include related **sub-jobs** that support the main goal.
- Summarise what success looks like from the customer’s perspective.

---

### Step 2: Identify Emotional and Social Jobs

- **Emotional jobs:** How users want to *feel* before, during, or after using the product.
→ e.g., “Feel motivated,” “Feel secure,” “Feel in control.”
- **Social jobs:** How they want to *be seen* by others.
→ e.g., “Look responsible,” “Appear successful,” “Be part of a community.”
- Explain how these jobs shape usage or purchase decisions.

---

### Step 3: Explore the Customer’s Context

- Describe **when, where, and why** this job arises.
- Identify **triggers** (events or moments that make the job relevant).
- Note **barriers or frustrations** that stop customers from achieving success today.
- Mention differences across **customer segments** (e.g., beginner vs expert, urban vs rural).

---

### Step 4: Map Current Solutions

- Identify what customers are currently using to get this job done:
    - **Direct competitors** (same solution type)
    - **Workarounds** (manual or DIY methods)
    - **Substitutes** (different category achieving the same goal)
- Analyse which aspects are **well-served** vs **underserved**.

---

### Step 5: Synthesize Key Insights

- Summarise the **true intent** behind customer behaviour.
- Identify **unmet needs** or **innovation opportunities**.
- Suggest 2–3 product implications:
    - Simplify the core job
    - Address emotional or social needs
    - Introduce moments of delight

---

### Output Format

End with a **JTBD Insight Table:**

| Job Type | Description | Importance | Current Satisfaction | Opportunity | Job Story |
| --- | --- | --- | --- | --- | --- |
| Functional |  |  |  |  | When [situation], I want to [motivation], so I can [desired outcome]. |
| Emotional |  |  |  |  | When [situation], I want to [motivation], so I can [feel outcome]. |
| Social |  |  |  |  | When [situation], I want to [motivation], so I can [project or belong]. |

---

### Final Step

Write a short summary paragraph:

> “Customers don’t just want [feature]. They want to [core job].
> 
> 
> The biggest opportunity lies in improving [underserved outcome], especially when users [specific trigger/context].”
> 
> Create top 10 Product ideas for this product
